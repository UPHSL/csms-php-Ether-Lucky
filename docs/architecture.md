# PHP Laravel Application Architecture

## Overview

The PHP implementation of the Community Services Management System uses Laravel.

The starter repository establishes a common application architecture before major CSMS functionality is introduced.

Students should preserve this structure throughout the semester unless a ticket specifically requires an architectural change.

The architecture is designed to demonstrate:

- separation of concerns;
- object-oriented design;
- layered application responsibilities;
- Laravel routing and controllers;
- service-oriented business logic;
- repository-based persistence abstraction;
- automated application testing.
