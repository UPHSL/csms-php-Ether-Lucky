# PHP Laravel Developer Handbook

## Community Services Management System

This handbook explains how to work on the PHP/Laravel implementation of the Community Services Management System for the Programming Languages Laboratory.

Use this guide together with:

- `docs/architecture.md`
- `docs/git-cheatsheet.md`
- `docs/release-workflow.md`
- the assigned GitHub ticket
- the official Moodle activity

Moodle remains the official source for activity instructions, deadlines, grading requirements, and submission requirements.

GitHub is used to manage the code, development history, branches, commits, pull requests, and technical work.

---

# 1. Technology Stack

The PHP implementation uses:

- PHP
- Laravel
- Composer
- Blade
- PHPUnit / Laravel Testing
- Git
- GitHub
- Visual Studio Code or another compatible IDE
