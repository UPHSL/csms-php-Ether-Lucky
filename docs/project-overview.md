# Community Services Management System

## PHP Laravel Implementation

The Community Services Management System is the semester application used in the Programming Languages Laboratory.

This repository contains the PHP implementation of the system using Laravel.

The application will be developed progressively through assigned sprint tickets. Students are not expected to complete the entire application at once. Each ticket introduces a specific requirement, programming concept, framework feature, or software engineering practice.

---
